### Create: Deco Dimmable Cage Lamps (Create: DDCL) - Dimmable cage lamps from Create: Deco.

Have you ever used Create: Deco cage lamps? They are a very good decoration block for your builds. However, i wanted to use them as night safety lamps or as low light level signal lamps in my factories.
Create: DDCL solves this problem by adding all create deco lamps in dimmable version.
You can adjust the light level by varying the redstone power input (which you can do with comparators or i also suggest using the sequenced pulse generator from Create: Connected).

## Content
The mod adds the following dimmable lamp version materials in red, blue, green and yellow colors:

- Andesite
- Brass
- Copper (also old create 0.5.1 version)
- Industrial Iron
- Iron
- Zinc
- Gold (not in Create: Deco anymore)
- Netherite (not in Create: Deco anymore)

All the lamps can be obviously used as normal Create: Deco lamps since if you fully power them, their behaviour is the same as normal ones.

There is also a create ponder that explains how the lamps work.

The installation process of this mod is the same as every other mod: install this mod jar and the dependencies (Create and Create: Deco) jars
in your mods folder.
